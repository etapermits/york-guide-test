MYGLOBALTOURGUIDE — YORK FIELD TEST

Main page: index.html
Audio: audio/*.mp3

GitHub Pages upload:
1. Create a new PUBLIC GitHub repository, e.g. york-guide-test.
2. Upload index.html AND the complete audio folder to the repository root.
3. Commit the files.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch: main, folder: /(root), then Save.
7. GitHub will display the live Pages URL after deployment.

Do not rename or move the audio folder unless you also update the audio paths in index.html.
